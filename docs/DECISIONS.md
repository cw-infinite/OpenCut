# OpenCut implementation decisions

- User-requested name **OpenCut** overrides LocalCut throughout the supplied spec, including `%APPDATA%/OpenCut`.
- Milestones follow the supplied order; unimplemented editing capabilities are labelled rather than simulated.
- Electron 44.5.1 was the latest stable version returned by npm at bootstrap. Vite 7 is used because electron-vite 5 declares support through Vite 7.
- Whisper CPU binary is pinned to official v1.9.2 with the published SHA-256. The latest release metadata (v1.9.4) had no binary assets. Both model downloads have pinned SHA-256 checksums from the official Hugging Face repository.
- Downloading is explicit via the setup button or command. Normal renderer requests are limited to local resources; development additionally allows its loopback Vite server.
- Downloads stream to `.part` files, verify their checksum, and then replace the target. Optional `--small` downloads the higher-accuracy model too.
- Bundled tools live in `resources/tools` in development and the portable app's resources directory after packaging.
- The scaffold uses an original restrained graphite/lime interface and bundled Inter. No CapCut assets are included.
- Tailwind 4.3.3, Vitest 4.1.11 and Electron's maintained ZIP extractor replace older bootstrap dependencies after audit findings. Final M0 dependency audit reports zero vulnerabilities.
- The spec's PRJ-2 long-edge 1080 wording conflicts with its 1920×1080/1080×1920 export presets. Canvas settings support both explicit 1080p orientations; short edge is capped at 1080 and long edge at 1920.
- Project mutations save immediately and atomically; the prior valid JSON is retained for crash recovery. Imported source files are never copied or deleted. Duplicating a project copies its proxy/cache files so either project can be deleted independently.
- Project FPS is fixed after import in M1 because CFR proxies use the project rate. Changing FPS requires a new project until proxy regeneration is implemented.
- Media protocol responses explicitly serve HTTP-style byte ranges: forwarding file responses did not produce seekable video in Electron's custom protocol handler.
- M1 automated acceptance uses generated 1080p variable-frame-rate footage with audio, an MP3, and a transparent PNG. This does not constitute testing the full real-phone/long-audio media corpus.
- Timeline history retains 200 Immer patch steps. Linked clip edits preserve audio/video timing; copied and split groups receive independent link IDs.
- Export freezes a saved project snapshot and uses a separate hidden sandboxed window calling the same compositor. One RGBA frame at a time crosses typed IPC; FFmpeg stdin backpressure gates the next frame.
- Export renders to a uniquely named sibling `.partial.mp4`, then renames only on success. Cancellation cleans the partial file and temporary audio mix. Existing chosen output is preserved on failure/cancellation.
- Audio delays are expressed in 48 kHz samples to avoid millisecond rounding drift. Silent edits receive a duration-matched silent mix. In/out ranges trim the mixed content without changing source files.
- Encoder selection tests each GPU encoder with the actual output dimensions/settings before selection. Runtime GPU failure retries with libx264. NVENC and software output have both passed on this machine.
- Preview/export frame comparison allows small RGB errors from H.264's lossy encode and YUV420 color conversion; it does not claim byte-identical compressed output.

- Visual keyframe easing belongs to the outgoing key. Curves clamp to their first/last value outside the keyed interval. Trimming/splitting retains keys outside the visible clip range (including negative clip-relative times) so nonlinear curves remain exact rather than being approximated.
- Custom Bézier controls are constrained to the unit square to avoid transform/opacity overshoot.

- Speed supports 0.1–100 in 0.01 increments. A rational timing grid preserves integer microseconds and the exact source-span invariant; fractional speeds may trim less than 10 ms from the source end. Later clips on the track ripple. Preview media playback above 16× may seek/chop; exported speed remains exact.
- Transition edits require adjacent clips and prevent triple overlap. They ripple the affected track; unlink detached clips before changing overlap. Audio crossfades linearly across transitions.
- Reverse creates local derived media, processing at most two seconds of video per FFmpeg reverse operation. Freeze captures a frame-aligned PNG and adds a five-second still on a new track. Derived originals are copied when duplicating projects.
- Ordinary audio keyframe easing uses exact FFmpeg expressions; custom Bézier gain uses 64 piecewise-linear segments and FFmpeg audio-frame evaluation.

- Text uses the shared canvas compositor for preview and export. Active fonts are loaded before layout. Whole-title styles are cached as transparent layers; per-character/word/line animations render individual glyphs.
- M5 verification compares real decoded 1080p frames at entrance, middle, and exit for both automatic (NVENC on this machine) and software encoding. Saved text content, animations, and custom styles are checked after reopening the timeline. The prior title-export timeout did not reproduce on resumption; the existing cached renderer completed the 60-frame export in about two seconds with NVENC.

References: [electron-vite requirements](https://electron-vite.org/guide/), [official Whisper releases](https://github.com/ggml-org/whisper.cpp/releases), [official model repository](https://huggingface.co/ggerganov/whisper.cpp).

- 0.5.1 normalizes waveform caches at the media IPC boundary. Both plain arrays and the older `{ buckets, peaks }` format return finite, bounded sample arrays. Corrupt or missing disposable waveform data returns an empty waveform without rewriting projects or source media. Regression testing reproduced the original `peaks.slice is not a function` crash and verifies Projects restore/navigation after the fix.

- M6 ducking uses speech-clip activity, with attack before speech and release after; overlapping envelopes use their minimum gain. Noise reduction and loudnorm are export-only and labelled in the inspector.
- Beat markers use local energy-onset detection; they are candidates, not guaranteed musical downbeats. Existing timeline snapping targets them.
- Voiceover requires an explicit record action. Only the main editor may request audio capture; M9 adds explicitly authorized camera/display capture while hidden workers remain denied. Recordings are converted to PCM WAV before import to recover reliable duration metadata. Automated tests use a fake microphone.
- AAC ADTS duration estimates can be inaccurate; audio export acceptance measures decoded samples instead.

- M7 core uses bundled base.en, CPU-only Whisper full JSON with word-sized segments. Offsets from Whisper are milliseconds; stored word times are clip-relative microseconds. Whole-timeline/range generation uses the audible mix; selected-clip generation isolates its audio, preserves speed/reversal, and restores the clip timeline offset.
- Caption chunking defaults to 32 characters, two lines, six words, punctuation boundaries, 400 ms minimum where the next cue permits, and five-second grouping. A single overlong word is kept intact. Imported SRT is plain text and rejects overlapping cues; it has no invented word timings. Text edits clear word timings. Trim/split shifts metadata like animation keys.
- Caption generation has explicit cancellation, temp cleanup and process termination on app quit. The renderer cannot choose executable/model paths. The model selector accepts base.en or small.en; downloads are explicit and animated/filler controls are implemented.

- M7 animated presets use clip-relative word metadata; wrapped glyphs retain original word identity. Merge/split preserve timing when it is available. Filler cuts remove an interval across all tracks as one undoable edit and refuse locked tracks, cuts through transition overlaps, or nonrepresentable source timing units.
- Long-speech acceptance initially measured 541 ms phrase-onset error. DTW token centers plus measured quiet-gap boundary refinement reduced the same two-minute synthetic fixture to 110 ms. Whisper 1.9.2 requires `-nfa` with `-dtw`; flash attention silently disables DTW. Punctuation tokens are excluded from word centers. [Whisper token timing API](https://github.com/ggml-org/whisper.cpp/blob/v1.9.2/include/whisper.h). This does not establish 200 ms accuracy on arbitrary human speech.
- small.en download uses the existing checksum-verified setup path and only starts after the explicit download button. Its model path is whitelisted. The optional model has not been installed for the current automated gate.

- M8 uses the shared CPU canvas compositor for filters, masks, chroma key, effects and PiP. Working surfaces cap their long edge at 1920 pixels. Noise/motion are deterministic by clip time. Transition composites use the incoming clip's blend mode. Long-project/performance targets remain unverified.
- M9 batch outputs share one immutable project/media snapshot, render sequentially, and receive unique file names. Completed outputs survive cancellation. Quality-based size estimates are heuristic; custom bitrate and PCM estimates use nominal rates. Platform presets change only output dimensions; existing fit/crop controls determine framing.
- Frame images render at project resolution, independent of preview quality. Covers use an atomic project-owned PNG and are copied on duplication. Relinking prepares new caches before swapping the asset under its existing ID, and rejects incompatible types, lost required audio, and source ranges longer than the replacement.
- Silence detection runs on trimmed, reversed, speed-adjusted source audio. Review leaves 50 ms padding at each edge. Removal uses the same cross-track ripple/undo constraints as filler cuts.
- Video recording requires an explicit camera or screen/window selection. Windows system audio is opt-in and captures all playing apps. Electron reports an empty mediaTypes list for display capture; this is accepted only with a pending, expiring source selection from the main editor. Capture is bounded to five minutes/120 MB in the renderer and 128 MB at IPC. Tests use a synthetic camera/microphone and only the isolated test window; real devices and desktop/system-audio capture remain manual checks.

- 0.9.1 replaces native timeline clip drag/drop with pointer gestures. A transient project supplies live group previews; only release writes one validated history entry. Marquee selection tests clip rectangles in content coordinates and supports scrolling/direction changes. Shift/Ctrl-click toggles exactly one clip; normal clicking still selects linked partners. Delete and bulk edits operate on the explicit selection.
- Group duplication uses the selection's full temporal span, regenerates IDs/link IDs, and makes room on affected tracks. A nonselected clip crossing the insertion boundary must be split first. Overlap/lock failures leave the saved project untouched.
- Preview display size is computed from viewport dimensions and project aspect ratio, independently of canvas render quality and export resolution. Zoom enlarges this display with scrollbars. Fullscreen permission is restricted to the main editor; export workers remain denied. Interface CSS labels have a 14 px minimum; timeline rows and inspector sizing grow with the larger type.

- M10 transcript editing uses generated caption word times and selects one caption track at a time. Overlapping intervals are merged, then cut in descending order through the existing cross-track range editor. Word gaps remain. The entire operation is one atomic history entry; locked tracks and transition intersections retain existing protections.
- Stabilization uses the bundled FFmpeg deshake filter on the trimmed video proxy, with mirrored edges and original-source audio. It creates a project-owned derivative and retains speed, reverse direction, transforms and placement. This local method adds no model download and is intended for camera shake; moving subjects and large motion need visual review.

- Motion tracking samples an isolated source clip through the shared compositor at 10 Hz and a 320-pixel maximum edge. A fixed 17×17 RGB template searches within 20 pixels of the previous location; flat regions and high matching error are rejected. It is a bounded template tracker, not semantic object detection, and can confuse similar subjects or fail under occlusion, zoom or rapid movement. Clips are limited to 60 seconds per analysis.
- Tracking creates ordinary X/Y keyframes on an existing text/image overlay, preserving its initial offset and animation outside the source interval. Results are tied to the analyzed project snapshot, and application is an atomic undoable edit. Cancellation disposes the decoder without saving partial movement; no new IPC or downloads are needed.

- Preview gestures use a transient project, coalesce pointer moves to animation frames, and commit one validated edit on release. Scale follows radial distance from the clip center and rotation follows pointer angle. Escape, pointer cancellation, lost capture and window blur discard the preview.
- Marquee hit testing caches content-space clip rectangles at gesture start; scrolling changes the pointer coordinates rather than rereading every clip's layout. Tests now assert selection and rectangle position before pointer release, and keep target coordinates inside the visible timeline.
- Library drag metadata supplies placement previews while native drag payloads are protected. Drop areas insert a correctly typed track at the chosen stack position; an incompatible lane creates a new track above it. Existing compatible lanes retain lock and overlap validation. The editor has a bounded window layout so timeline interaction does not scroll the entire page.

- Bulk text styles operate only on homogeneous text/caption selections and validate every selected clip before mutating styles. Individual controls change only their property; enabling an appearance feature preserves existing settings and supplies defaults only where missing. Style presets explicitly replace the full style. Caption content, word metadata, transforms and animations are retained. Blank/mixed controls and indeterminate checkboxes distinguish mixed values from shared values.

- Smart reframe analyzes uncropped source display geometry and writes fill-mode X/Y keys into the current canvas. Edge clamping prevents exposed borders; crop/transform are explicitly replaced while timing/audio remain intact. The existing user-selected template tracker provides the path.
- Local creative IPC trusts only the editor, serializes jobs and locks media-library mutations during generation. Piper receives plain text through stdin with fixed executable/model paths. Setup is explicit and checksum-pinned; generation uses bundled or user-data models offline.
- MODNet CPU inference reads one RGB frame at a time from temporary disk storage and writes grayscale mattes. Processing is bounded to 30-second video source spans and a 512-pixel analysis edge. FFmpeg combines the matte into alpha WebM or PNG; alpha video bypasses opaque H.264 proxies. Cancellation removes partial outputs and temporary frame storage.
- Preview resources track media URL identity as well as clip ID so undoing a generated-media replacement reloads the correct source. Desktop tests compare cutout preview before/after undo and exported MP4 frames.
